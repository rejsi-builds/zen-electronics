## 2. Usage Instructions

### Administrator

- Log in to the system
- View low-stock notifications (view only, no stock modification)
- Create Manager and Cashier accounts (enter employee details)
- Change an employee's role (e.g. Cashier to Manager or vice versa)
- Delete an employee account
- Search for an employee by name
- View employee profile

### Manager

- Log in to the system
- Create Cashier accounts (enter employee details)
- View employee profiles
- Search for employees by name
- View low-stock notifications and inventory status
- Restock low-stock items
- Create new inventory items (enter item details)
- Delete specific inventory items
- Apply discount to a specific item or an entire sector
- Generate sales report
- Identify Employee of the Month based on monthly turnover

### Cashier

- Log in to the system (multiple cashiers)
- Add items to the shopping cart
- Select payment method
- Complete checkout and print bill/receipt
- Automatically update inventory stock after sales
- View daily bills and daily turnover reports
